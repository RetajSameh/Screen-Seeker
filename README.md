# ScreenSeeker

ScreenSeeker is a team-based web development project designed to help users explore and discover movies and TV shows through an organized and user-friendly interface.

The project focuses on presenting entertainment content in a clear and engaging way, making it easier for users to browse and explore available titles.

**My Contribution:** I was responsible for implementing the responsive CSS, adapting the interface to different screen sizes, and improving the layout across desktop, tablet, and mobile devices.

**Project Type:** Team Project

**Focus:** Responsive Web Design and Front-End Development
